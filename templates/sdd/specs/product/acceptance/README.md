# Shared acceptance

A Feature's own criteria remain in its specification. Use this folder for scenarios spanning several Features and reusable business examples.

## Scenarios

Create `scenarios/SCN-NNN-short-description.md` with the [scenario template](../templates/acceptance-scenario.md) when a shared journey is needed.

## Examples

Create `examples/EX-NNN-short-description.md` with the [example template](../templates/acceptance-example.md) when reusable synthetic data clarifies defined behavior. Derive expected outcomes from existing rules and criteria; sample values do not introduce requirements. These examples express business behavior; fixtures specific to a test tool belong to the implementation.

Create `scenarios/` and `examples/` when adding content. Retain execution results per profile.
