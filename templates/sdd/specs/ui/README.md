# User experience

Complete the visual definition when a graphical interface exists. Describe tasks, layout, navigation, interactions, and states independently of the framework.

| Document | Content |
| --- | --- |
| [Principles](principles.md) | Shared experience and accessibility criteria. |
| [Navigation](navigation.md) | Conceptual destinations and journeys. |
| [Layouts](layouts.md) | Reusable content structures. |
| [Components](components.md) | Shared interaction patterns. |
| [Pages](pages/README.md) | Specifications for concrete tasks and screens. |
| [Page template](templates/page.md) | Canonical structure for each page. |
| [Flow template](templates/flow.md) | Shared journeys across pages. |

Create `flows/FLOW-NNN-short-description.md` with the flow template when journeys between several pages need their own description. Pages and flows reference the Features they realize and the existing contracts they use.

If the product has no graphical interface, record that this area does not apply in its overview and define the corresponding channel's experience.
