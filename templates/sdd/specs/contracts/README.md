# Interaction contracts

Contracts describe stable operations independently of transport, runtime and framework. Each operation references the Features and shared rules that define its observable behavior.

Use the [operation template](templates/operation.md). Store records in `operations/CON-NNN-short-description.md` and start new contracts as `draft`. Use `ready` after a documented specification review and `deprecated` when retired.
